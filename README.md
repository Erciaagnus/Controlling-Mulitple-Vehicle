## 📌 Project Theme
This project explores control strategies for multiple autonomous vehicles operating within a networked system. The focus is on both centralized and distributed coordination using advanced control methods.

We implement and compare the following approaches:

- ✅ **Centralized Model Predictive Control (MPC)**
- ✅ **Distributed Model Predictive Control (DMPC)**
- ✅ **Priority Based Distributed Model Predictive Control (PB-DMPC)**

These controllers enable collaborative decision-making across a fleet of vehicles with the goal of improving stability, scalability, and performance in networked environments.


## 📅 Project Duration
**October 2024 – February 2025**

## 🛠️ Technologies Used
- Python3
- ROS2 / RVIZ
- Optimization frameworks (SCP, QCQP)


## 🚀 Goals
- Develop scalable control algorithms for multiple autonomous vehicles.
- Simulate cooperative behavior in dynamic environments.
- Benchmark centralized vs. distributed MPC in terms of performance, computation, and communication.
